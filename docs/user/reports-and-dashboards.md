# Reports and Dashboards

TA Connect does not currently have a separate reports or dashboards page. The Requests and Experts pages provide the current on-screen summaries, filters, and export functions.

## Review request activity

Open **Requests** to review work in progress and closed work. The **Active** tab separates requests into **Actionable** and **Downstream** groups. The **Inactive** tab contains completed requests and requests marked unable to address.

Use the controls above the list to:

- search the request data shown to you;
- filter by program; and
- sort by newest, oldest, or status.

Each request card shows the customer, state, request number, status, depth, and creation date. Open a request to see its full details, closeout information, and audit history.

## Review expert activity

Open **Experts** to see expert name, laboratory, areas of expertise, active request count, and total request count. Use the table toolbar to choose columns, apply filters, or search the table.

Admins can turn on **Admin Mode** to include system-wide expert data. Other users see the experts available within the scope of their roles.

> **Screenshot placeholder:** Experts table with column, filter, search, and export controls highlighted.

## Print or export expert data

To export the current Experts table:

1. Apply any filters or search terms needed for the report.
2. Click the **Export** icon in the table toolbar.
3. Select **Print** or **Download as CSV**.

The CSV can be opened in a spreadsheet application. Check the exported rows and columns before sharing the file, especially if the table was filtered or columns were hidden.

Request-list CSV export and configurable dashboard charts are not available in the current user interface.
