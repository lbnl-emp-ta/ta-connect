# TA Connect

TA Connect is a technical assistance (TA) tracking and reporting platform. It enables partnered National Laboratories, each hosting various TA programs, to coordinate their efforts and gives funders and partners a shared view of TA work through reports and dashboards.

TA Connect is a full-stack web application with a Django REST Framework backend and a React frontend.
